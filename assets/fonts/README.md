# Fonts

Fonts are currently loaded from Google Fonts (see the `<link>` in each page's `<head>`):
Inter, Plus Jakarta Sans, Noto Sans Telugu and JetBrains Mono.

To self-host, place the `.woff2` files here and declare them with `@font-face`
in `assets/css/base/typography.css`, then remove the Google Fonts `<link>` tags.
